# v3.6 — Storage foundation

Phase 4 introduces an independent, opt-in SQLite persistence package. It uses
Python's standard library, explicit paths, versioned schema migrations and
namespaced records. It is not connected to server startup or exposed through
MCP/API tools. See `docs/v4-phase4-storage-foundation.md`.

Validation: 10 storage tests, 14 API service/client tests and 173 MCP tests
passed. 16 API HTTP tests and 45 MCP tests were skipped because the isolated
Laptop MCP environment blocks local TCP loopback/live jail networking.
