# v3.16 — Optional RAG modules

Phase 5.5 adds explicit application-level switches for RAG and embeddings.
Both modules default to disabled. Keyword retrieval can be enabled independently
of embeddings; semantic operations require both switches and an explicitly
provided `EmbeddingProvider` implementation.

Disabled RAG does not construct a store, access or initialize a supplied
SQLite database, remove existing records, call a model or make network requests.
Enabling RAG requires an already initialized database supplied by the caller.
No embedding provider, model, API key, SDK, second LLM, sub-agent, MCP tool or
API endpoint is added. MCP/API startup remains unchanged.

See `docs/v4-phase5.5-optional-rag-modules.md` for configuration and lifecycle
semantics. Validation results are recorded in `RELEASE.md`.
