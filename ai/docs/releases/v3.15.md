# v3.15 — Semantic retrieval foundation

Phase 5.4 adds a provider-neutral embedding interface, strict vector validation,
SQLite persistence for chunk embeddings and exact cosine-similarity retrieval.
Callers must explicitly supply an `EmbeddingProvider`; no provider SDK, API
credentials, network client or default embedding model is included.

Vectors are stored per chunk with provider/model identity and content metadata.
Indexing is performed explicitly, calls the provider outside the database
transaction and checks document/chunk fingerprints before committing. Changed
or re-chunked documents invalidate vectors; unchanged chunks retain them.
Semantic search is an exact in-process scan with source/document filters and
optional per-document deduplication. It is intended for small corpora only.

RAG remains disconnected from MCP/API startup. No public tools/endpoints,
background jobs, automatic ingestion, vector database or live host integration
are introduced.

Validation results are recorded in `RELEASE.md`.
