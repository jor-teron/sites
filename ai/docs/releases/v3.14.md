# v3.14 — RAG retrieval improvements

Phase 5.3 extends `RAGStore.search()` with exact source and document-ID filters,
bounded query-centred snippets, optional per-document deduplication and an
inclusive BM25 score ceiling for initialized FTS5 searches. Ranking now has
stable tie-breaking. The portable LIKE fallback supports the filters, snippets
and deduplication but does not expose a relevance score or threshold.

The search result keeps the full chunk text alongside its snippet and retains
an optional score field, providing a stable seam for future retrieval backends.
No embeddings, vector search, reranking, LLM calls, MCP/API integration or
public endpoints are added. RAG remains opt-in and disconnected from server
startup.

Validation results are recorded in `RELEASE.md` after the full regression run.
