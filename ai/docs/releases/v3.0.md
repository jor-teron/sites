# v3.0 — Filesystem hardening

- Introduced descriptor-relative path handling in `mcp/safepath.py`.
- File tools now anchor operations to directory descriptors rather than relying on path validation followed by a separate pathname operation.
- Symlinks are treated as entries and are not traversed during recursive listing or deletion.
- Added protections for final-component symlinks, FIFOs and parent-directory replacement races.
- Validation at release: 158 tests total; 113 passed and 45 network-dependent tests skipped in the restricted environment.
