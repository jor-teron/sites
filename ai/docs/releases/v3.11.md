# v3.11 — RAG ingestion foundation

Phase 5.0 adds a standard-library-only, in-memory document ingestion pipeline
under `rag/`. It accepts UTF-8 text/bytes for TXT, Markdown and HTML, removes
non-visible HTML script/style/template/SVG content, normalizes text and
produces overlapping character chunks with source offsets. Document metadata
includes a deterministic ID, content SHA-256, title, source label, content
type, character/chunk counts and ingestion timestamp.

The input limit is 5 MiB. PDF/DOCX, OCR, directory crawling, persistence,
embeddings, vector search, retrieval, MCP tools and API endpoints are not part
of this phase. The caller supplies content; the pipeline does not open source
paths, access the network or write to SQLite.

Validation: 15 RAG tests, 24 storage tests, 14 API service/client tests and
173 MCP tests passed. 16 API HTTP tests and 45 MCP tests were skipped because
the isolated Laptop MCP environment blocks local TCP loopback/live jail
networking. Python compilation, shell syntax and `git diff --check` passed.
