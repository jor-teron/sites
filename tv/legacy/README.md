# tv/legacy

Retired TV players and orphaned files, kept for reference only. Not maintained.

- `tv-v2.*`: TV Player v2
- `tv-v3.html`, `tv-v3-more.html`, `tv-v3.css`, `js/`: TV Player v3 and its modules
- `kids.html`, `india.html`, `world.html`, `kids-mini.html`: v3 single-playlist pages
- `tv-v3.js`: old all-in-one v3 script (was never loaded)
- `photo.html`, `video.html`: "Coming soon" placeholders
- `tv-old/`: the original Android TV homepage launcher

Moved here in TV4 (2026-10-23). Paths were not updated, so links, CSS, `channels/` playlists and icons may be broken. The current player is `../tv-v1.html`.
