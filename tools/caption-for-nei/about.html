What it does

  • Input: Auto / English / Assamese / Hindi / Bengali / Nepali → live transcript
  • Output Off = transcript only. English / Hindi / Assamese / Bengali / Nepali = chat translate
  • Model: Auto rotate or pin 3.5 Lite / 3.1 Lite
  • Mic bar shows loudness. LED green = caption session on
  • RPD counters reset 00:00 UTC (set limits in caption-for-nei_config.js)
  • Vocab files: city.csv, town.csv, surname.csv, vocab.csv

Parked

  • ABC / romanization
  • 2-panel layout
  • Karbi
  • Local Pack (on-device)
  • Live Translate output
  • Speaker / translated audio

Notes

  • API key stays in this browser. Do not publish it.
  • Audio is sent to the cloud while Start is on.
  • A live session may drop after about 10 minutes. Tap Start again.
  • 500 RPD on Lite is a hard project cap if Google applies it that way.
