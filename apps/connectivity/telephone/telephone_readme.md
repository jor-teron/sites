# Telephone — TP1

Phone calls between devices on the same Hub Connect Code (Connectivity → Chat, after Intercom). Each device gets its own 4-digit number; dial it and only that device rings.

- **Number:** made once at random (`2000`–`9999`, never starting with 0 or 1), saved and shown big on the Phone screen. Settings → New number makes another one. If another device (different `did`) that came online earlier already has the same number, this device takes a new free number and says so in an in-app dialog.
- **Code:** `#code=1234` / `?hub=` (QR), the Hub's `{sharedLink:'hello'}` after `{sharedLink:'ready', app:'telephone'}` inside the Hub, `parent.__hubRemote.code`, `jtsites-hub-ctrl-code` / `shared-link-join-code`, the last code (`telephone-last-code`), else the Code dialog.
- **Peers (own, never the Hub's):** `jtsites-<code>-telephone-<random>` per device; lobby `jtsites-<code>-telephone-0` claimed by the first device keeps the roster (`hi {id, name, num, did, busy, since}` → `roster`) and relays `{t:'to'}` signals to one device. A remaining device claims the lobby if it goes (random 0.3–1.8 s). PeerJS from `SharedLink.PEERJS_URL` (`shared/link/link_core.js`), pinned peerjs 1.5.4.
- **Calling:** keypad (DTMF key tones, 4 digits, keyboard digits / Backspace / Enter) or tap a phone in Online now. The mic is asked for first, then `{t:'ring', cid, num, name, did}` goes ONLY to the device with that number (the newest one if two tabs share it). The callee acks `{t:'ringing'}` (none in 6 s → "Could not reach the phone") and shows the ringing screen with Answer / Decline (ringtone, vibrate, Hub notice when hidden). The caller hears ringback (440+480 Hz, 2 s on / 4 s off).
- **Answer:** callee gets its mic, sends `{t:'answer'}`; the caller opens one audio MediaConnection (metadata `{kind:'phone', cid, num, name}`), which the callee answers only if the peer and `cid` match. 15 s to connect, else "Call could not connect".
- **Not connected:** no answer in 30 s → `{t:'cancel', why:'timeout'}`, "No answer" (missed on the other side). Callee already in a call → `{t:'busy'}` → "Busy" + busy tone (480+620 Hz) and a missed entry "(you were on a call)" on the callee. Decline → "Call declined". Unknown number → "Not online" + three rising notes. Own number → dialog.
- **In a call:** timer, Mute (mic track off + `{t:'mute'}` so the other side sees "muted their microphone"), Speaker (`setSinkId` output picker where the browser supports it; `selectAudioOutput` on Firefox; otherwise a note that the browser chooses), Hang up (`{t:'hang'}` + close). Esc hangs up, Enter answers. A device leaving the roster ends the call ("Call dropped").
- **Recent calls:** incoming ↙, outgoing ↗, missed ✕ (red), with time, length or reason; tap one to call back; Clear asks first.
- **Files:** `telephone_save.js` (the one save module: `telephone-settings-v1` `{name, theme, num, did, volume, sink, keytones}`, `telephone-log-v1` (newest first, max 100), `telephone-last-code`, theme), `telephone_peer.js` (presence + one-device signals), `telephone_call.js` (call state, media, tones), `telephone_app.js` (UI, swipe, dialogs), `telephone.html/.css`, `telephone_icon.png`.
- Screens: Phone · Recent · Settings (dots, 75 px wrap-around swipes). Controls on the right on wide screens; on phones the keypad sits under the number and the online list below it. Dark by default; System follows `sites-hub.theme`.
- Limits: a call rings only while Telephone is open on the other device (the PH1 launcher plan keeps it open on a phone). Phones usually do not let a web page switch between earpiece and loudspeaker. One call at a time; contacts, missed-call badge, DND and video are TP2.
