# Contacts (CT1)

One contact list shared by Contacts, Telephone and Messages (`../shared/contacts_store.js`, `window.HubContacts`,
localStorage `telephone-contacts-v1`, max 200). Search, ⭐ favourites on top, add / edit / delete.
Tap a contact → 📞 Call (`telephone.html#dial=<num>`), 💬 Message (`messages.html#chat=<num>`), 🎥 Video call
(`telephone.html#dial=<num>&video=1`, camera turns on once the call connects). Green dot = online on the Hub Line.

Files: contacts.html, contacts.css, ct_theme.js, ct_open.js, ct_app.js, index.html (redirect only).
