# Notepad

One plain-text note in this browser (`localStorage` key `notepad-text`). Download saves `My_note.txt`.

## HO2

Typing saves itself after a short pause, and again when you leave the tab or hide it, so closing the page does not drop text that the Save button had not written yet. If the disk is full or storage is blocked, a card stays up ("Couldn't save — storage full" or "Couldn't save — storage blocked") until a save works. Loading does not replace text already in the box with an empty store.
