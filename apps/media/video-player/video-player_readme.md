# Video Player (VPL1)

Minimal player for your own video files. Nothing is uploaded.

**Open** a file, a folder, or drop one in. A folder shows a simple list you can hide. Playback **resumes** where you left each file. **SRT/VTT** subtitles load from a matching name in the folder, or from *Load subtitle…*. Speed is 0.5×–2×. Skip 10 seconds with the arrow keys. Picture-in-picture is in the ⋯ menu.

**Keys:** Space play/pause · ← → 10 s · ↑ ↓ volume · F full screen · M mute.

Plays whatever this browser supports (usually MP4 H.264, WebM, and some MKV). Other types show a plain message. Offline, no libraries. Auto / Light / Dark theme.

Release id: **VPL1**. Files: `video-player.html`, `video-player.css`, `video-player.js`, `video-player_helpers.js`.
