API & Providers

These are Agent's own settings. Agent no longer uses the Hub's API Keys: add the keys and providers Agent should use here, even if you already saved them in the Hub. Changing them here does not change the Hub, and the Hub's changes do not reach Agent. Nothing is copied between them.

🔒 Saved only in this browser on this device (localStorage, not encrypted). That is not a security boundary: other pages on this same site can read it. Key fields stay masked; a saved key is never shown again (type a new one to replace it, or Clear / Delete to remove it). Agent sends a key only to that provider.

Browsers can only call APIs that allow it (CORS). Ollama needs OLLAMA_ORIGINS; some providers need a proxy, which Agent does not supply. "Test" only lists models; it does not prove chat works or that you have credits.

Agent uses: Tavily (web tools), Ollama URL, Gemini, the provider rows (OpenRouter, Groq, DeepSeek, OpenAI, xAI, DeepInfra) and any custom OpenAI-compatible provider. Cloud Vision is not used by Agent. Pollinations and the Browser model need no key.
