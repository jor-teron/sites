Image Gen release IG1

Makes pictures from a text prompt with an image model on your own Ollama (for example x/z-image-turbo or x/flux2-klein). Images are kept on this device only.

Ollama image generation is experimental (macOS). Versions 0.32.6 and later have it turned off; use 0.32.5. To let this site reach Ollama, start it with OLLAMA_ORIGINS=https://jor-teron.github.io.

Swipe left/right or use ←/→ to switch screens.
