Image Gen release IG4

Makes pictures from a text prompt with an image model on your own Ollama (for example x/z-image-turbo or x/flux2-klein). Images are kept on this device only.

IG3: start photo (image-to-image, see the note under Start photo), Upscale 2× on this device, Compare two gallery images or before/after with a slider, Send to Gallery (saves a PNG to Downloads; open that folder in Gallery).

IG4: Engine Online (free) uses Pollinations (no key). The prompt is sent to Pollinations; images are cached there by URL. Ollama is unchanged.

Ollama image generation is experimental (macOS). Versions 0.32.6 and later have it turned off; use 0.32.5. To let this site reach Ollama, start it with OLLAMA_ORIGINS=https://jor-teron.github.io.
