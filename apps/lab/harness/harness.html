Start it in a terminal: bash helper/harness-helper.sh (needs socat or ncat; listens on 127.0.0.1 only). Every command shows an Approve / Deny card first.

Daily logs go to harness/chats/YYYY_MM/YYYY_MM_DD.md; memory to harness/memory.md; system prompt in harness/prompts/system.md (edit it there). In-app history stays in this tab (sessionStorage). Settings are saved.
