What these numbers mean

GFLOPS — Giga Floating-Point Operations Per Second: billions of FP32 multiply/add operations per second.

GOPS (integer arrays) — the same matrix multiply with Int8Array inputs and Int32Array results. JavaScript still does the maths as normal numbers, so this is not real INT8 / NPU speed and is usually close to the FP32 figure. 1,000 GOPS = 1 TOPS.

  • Latency — Time for one matrix multiply. Lower is better.
  • Sustained — Average speed over 10–15 seconds. Shows the drop after heating/throttling.
  • Memory-bound — Larger matrices stress memory bandwidth more than pure compute.
  • Story proxy t/s — one n×n matmul per "token", then a random word from a tiny list. It shows how many such steps per second the device manages. It is not a language model and not a real tokens/sec figure.
Disclaimer: Effective throughput of plain single-threaded JavaScript on the main thread (no WebGPU, no WASM, no workers yet). Matrix tests use real matmuls; the story tests are proxies, not model inference. Not datasheet TOPS. Useful for comparing devices under the same conditions.
