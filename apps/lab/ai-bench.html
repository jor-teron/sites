What these numbers mean

GFLOPS — Giga Floating-Point Operations Per Second. Measures how many billion floating-point calculations (mainly FP32) the system can do per second. Common for general compute and GPU performance.

TOPS — Tera Operations Per Second. One trillion operations per second. Usually refers to integer (INT8/INT4) AI accelerator performance. Vendors advertise NPU ratings in TOPS.

GOPS — Giga Operations Per Second (1,000 GOPS = 1 TOPS). Used here for the integer path because pure browser numbers are typically in the GOPS range, not full TOPS.

  • Latency — Time for one matrix multiply. Lower is better for responsive AI.
  • Sustained — Average speed over 10–15 seconds. Shows real-world performance after heating/throttling.
  • Memory-bound — Larger matrices stress memory bandwidth more than pure compute.
  • tokens/sec (t/s) — How many tokens a tiny story model can generate per second. Higher is better for chat-style AI. These are lightweight proxies (not full real model weights) so the test stays single-file and pure JS.
