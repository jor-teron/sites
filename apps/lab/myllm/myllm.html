myllm

A tiny character-level language model, trained from scratch in your browser. Pure JavaScript, no libraries.

1 · Model settings

What do these mean?

Tokens: each character is one token with its own ID number. Context: how many previous characters the model looks at to guess the next one.

Embeddings: each token gets a small list of numbers (a vector) that the model learns. The context vectors are joined in order, so “the” ≠ “eht”.

Parameters: all the learnable numbers (embeddings + weights + biases). Size = parameters × 4 bytes.

How does training work?

Forward pass: embeddings → hidden layer (tanh) → a score for every possible next character → softmax turns scores into probabilities.

Loss: cross-entropy = −log(probability of the correct next char). Random guessing gives about ln(vocab) ≈ 3.9; lower is better.

Backprop: works out how much each parameter caused the error. Optimizer (Adam): nudges every parameter a little to lower the loss, 32 examples at a time. The learning rate slowly decays.

Note: with a small text the model can memorize it (very low loss). Give it more text to make it generalize.
