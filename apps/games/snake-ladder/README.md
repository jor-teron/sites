# Snake & Ladder — SNL-2a / 2b / 2c

Open `snake-ladder.html` (the folder index redirects and preserves query/hash).
Classic scripts, no build, no external artwork or fonts. `assets/snake-ladder_icon.png`
is a 128×128 Pillow-drawn icon. SVG board art and CSS pawns/dice are generated locally.

## Releases

- **2a:** warm wood-rimmed board; filled tapered snakes with shaded skins, bands,
  scales, eyes and tongues; joined wooden rails/rungs; light/dark/Auto theme and shared
  settings gear; 1–100 labels; mobile layout; deterministic full-density generator;
  file layout migration and repaired VM-based test runner.
- **2b:** cell-relative sculpted pawns; grouped-cell offsets; per-cell hop arcs;
  snake rides along the same sampled curve used for the drawing; ladder climbs;
  pip die tumble; confetti; shared lowGraphics plus system reduced-motion support.
- **2c:** Human/CPU/Off seats; exact-100, extra-six and six-to-enter rules; validated
  save/resume; automatic CPUs; synthesized muted/volume-controlled sound; accessible
  help, controls and live journey; session cancellation for Quit/New game; catalog
  and progress-clear registration. Phone pip painting and full landscape fit verified.

## Important semantics

- Internal cells stay 0–99; displayed squares are 1–100. Seed IDs remain 00–99.
  Layouts are regenerated by the corrected algorithm, not the old deficient layout.
- Nine ladders and eight snakes require 34 distinct endpoints. A 10×10 grid can fit
  **at most 25** mutually king-separated endpoints. Thus diagonal neighbours between
  *different* connectors are allowed; endpoints never overlap or touch orthogonally.
  A connector's own ends are never adjacent: minimum two rows and 2.5 cells apart.
- This is a game of chance with no strategic move choice. Easy/Medium/Hard vary CPU
  pace and board-aware coaching, **not dice probabilities**. Every seat rolls the same
  uniform six-sided die. The UI explains this rather than pretending to offer skill AI.
- Six-to-enter consumes that six and places the pawn on square 1. Extra-six can then
  grant another roll. Overshooting 100 either stays put (default) or clamps to 100.
- The key `snake-ladder.save` stores a versioned snapshot of the last complete turn.
  Quit/reload during a die, hop or connector ride returns to that checkpoint. New game
  replaces it; a win clears it. Invalid data or unavailable storage never blocks play.
- CPUs wait while the tab is hidden or help is open; an already-started move finishes.
  Sound is generated only after a real user gesture and respects shared sfx/volume.

## Tests

From the repository root:

```sh
node apps/games/snake-ladder/test/board.test.js
node apps/games/snake-ladder/test/game.test.js
# Deprecated test path still forwards to the repaired runner:
node apps/games/snake-ladder/core/board-and-rules.test.js
```

Browser tests need Chrome and `puppeteer-core` / `pngjs` (not vendored into the app):

```sh
python3 -m http.server 8832 --bind 127.0.0.1
NODE_PATH=/workspace/snl-tools/node_modules node apps/games/snake-ladder/test/browser.cjs
```

`BASE_URL`, `CHROME_BIN`, and `SHOTS` can override browser test defaults.
The browser suite checks 390×844 and 844×390 in both palettes, actual screenshot-pixel pip
presence, pawn size, theme inheritance, reduced motion, shared settings and fallback,
seat validation, save/reload/resume, Quit/New game races, and a full four-CPU game.
That game's timers are accelerated to 2ms without replacing the real scheduler or
engine; a seeded fair RNG makes the result reproducible. The Node suite also completes
100 full CPU games (one per board) including periodic save/resume.

Screenshots live outside Git at `/workspace/snl_review/before-*.png` and
`/workspace/snl_review/after-*.png`; final portrait/landscape light/dark screenshots
were opened and visually reviewed. Real hardware/touch-device testing remains external.
