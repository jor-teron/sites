How to use History Timeline

  1. Choose World, India or both parallel lanes. The India lane includes the wider subcontinent and related events abroad, not just current borders.
  2. Deep-time mode compresses ancient millennia so recent eras stay readable. Spacing is unequal. Linear mode uses equal spacing for equal years.
  3. Drag to pan, wheel or pinch to zoom. Keyboard: focus the timeline, use ←/→ to pan, +/− to zoom and Home for all time. Use Decade for a ten-year window around your selected event or view centre.
  4. Tap a marker or an event button for a fact card. Crowded markers are sampled to stay usable: every event remains in the paginated list. In view only restricts the list to the current date window.
  5. Search event titles, filter topics and use ★ Bookmarks. Selected topics are combined; choosing All topics resets them. Bookmarks stay on this device only.
  6. At the same time lists all records within 25 years of the selected start date, ignoring filters. Approximate dates are still approximate. Pins mark representative places on a schematic map, not exact historical territories.
  7. Guided tours automatically visit a curated sequence every 8 seconds. Pause, resume or step manually; End tour leaves the timeline where you stopped. Direct dragging and zooming pause auto-advance. Tours also pause in a hidden tab or when a quiz opens.
  8. Ordering quiz: arrange five events from earliest to latest by dragging the handle or using ↑/↓. Century quiz: answer five questions. Both use exact-date records and save separate best scores locally.
  9. BCE means Before Common Era; CE means Common Era. There is no year zero. 1–100 CE is the first century CE; 100–1 BCE is the first century BCE. c. means circa, or approximately. Era boundaries are teaching conventions, not universal divisions.

This is a selective overview, not an exhaustive history. Ancient dates and period boundaries can change with new research. Quiz answers use only non-approximate event start dates.
