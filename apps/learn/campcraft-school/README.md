# Campcraft School

A small, phone-first outdoor skills learning app. Release 01 teaches the basics of a beginner freestanding dome tent through hand-drawn-style SVG diagrams and short, sequential lessons.

## Lessons
- Tent basics
- Pitch your tent

## Run
Open `index.html` in a browser or serve this folder from a local static web server. The service worker enables offline caching when served over localhost or HTTPS.

## Notes
Tent layouts vary. Follow the instructions supplied with your specific tent. Keep cooking equipment, flames and fuel-burning appliances outside the tent.
