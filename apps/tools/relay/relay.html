Relay

RY1

The Hub relay is a small program on your PC or Pi. Web MCP, SSH, VNC and fetch (WebDAV and API calls) all use it on one port. A web page can't start the relay: run it on the PC with the commands under Set up, then test it here.

Connection

Not tested yet.

    Saved on this device only (key hub.relay), so other Hub apps can use the same address. The token is stored in plain text in this browser.

    Endpoints

    Web MCP keeps its PIN. HTTP calls (/mcp, /fetch, /health) send the token as Authorization: Bearer … or X-Relay-Token; WebSockets use ?relay_token=. Don't share URLs that contain the token.

    Set up

    Needs Node 18 or newer. Stop the old Web MCP relay first: it uses the same port 8787. The relay listens on 127.0.0.1:8787 and runs until Ctrl+C.

    Install and start — Linux / macOS
    curl -fsSL https://raw.githubusercontent.com/jor-teron/sites/main/hub/relay/install.sh | bash
    Restart — Linux / macOS
    bash ~/.local/share/sites-hub-relay/start-relay.sh
    Install and start — Windows PowerShell
    irm https://raw.githubusercontent.com/jor-teron/sites/main/hub/relay/install.ps1 | iex
    Restart — Windows PowerShell
    node "$env:LOCALAPPDATA\sites-hub-relay\hub-relay.js" --config "$env:LOCALAPPDATA\sites-hub-relay\relay.json"

    Settings live in relay.json in the install folder; restart after changing it. Set a token with the HUB_RELAY_TOKEN environment variable. A secure (https) Hub on another device needs wss:// / https:// (TLS_CERT + TLS_KEY, or an HTTPS proxy) and a token.

    Allow lists

    SSH/VNC and fetch refuse every target until you list it. Add entries, then paste the result into relay.json (keys you leave out keep their defaults) and restart the relay.
