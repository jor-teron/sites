# Calendar Maker

## 1. What it is
Design and print a one-sheet A4 year calendar: all 12 months on one A4 sheet (4 layouts), title "YYYY", big bold dates and holidays as filled tiles. Releases CM1 (design page + print), CM2 (Download PDF, background, holiday list strip), CM3 (Holidays page), CM4 (grid tables, year-only title, white default background, layouts), CM5 (fold 6th week, fill the sheet), CM6 (month name inside the grid, Sun-Sat weekday row in holiday colour, custom colour, font colour, tight title), CM7 (folded dates drawn as normal dates, all grid lines same weight), CM8 (uniform spreadsheet grid), CM9 (restricted holidays), CM10 (Holiday List page), CM11 (multi-day holidays, Day + Month input for every-year holidays), CM12 (Classic holiday list layout), CM13 (code restructure into core/, render/, ui/; no visible change), CM14 (Year Overview page), CM16 (page tabs, Print and PDF in the Hub window title bar; CM16-F1 Legend size box; CM16-F2 striped holiday list rows; CM16-F3 Show restricted holidays switch; CM16-F4 plain Year Overview title and section gaps; CM16-F5 weekday row colour), CM15 (About page: Settings with app theme and reset, How to, About), CM17 (holiday list CSV export and import in About > Settings). Release label in the About line: CM17. Works offline and from file://.

## 3. Behaviour rules
- **Design (landing page):** live A4 preview. Options: Year (prev / next / type; default the current year, or `?year=YYYY` from Calendar's "Make printable"), Holiday colour (Green default, Red, Yellow, Blue, Orange), Colour Sundays (On), Saturdays as holiday (None / 2nd & 4th / All; default from Calendar's settings), Week starts (Sunday / Monday; default from Calendar's settings).
- **Grid (CM4):** each month is its own bordered table: month name above, grey weekday header row, thin lines between every day cell (5 week rows with CM5 fold on, 6 when off; empty cells included). Holiday tiles fill their cell.
- **Title (CM4):** just the year, e.g. "2027".
- **Layout (CM4):** Portrait 3 columns x 4 rows (default), Portrait 2 x 6, Landscape 3 x 4, Landscape 4 x 3. Preview, Print (`@page` portrait / landscape) and PDF follow it. Saved as `layout` in `calendar-maker-settings`.
- **Background default (CM4):** White ("None") to save ink.
- **Print:** the sheet is drawn to an image and only that image is printed (`@page A4` portrait or landscape to match the layout, margin 0; the sheet has its own ~4 mm margins and prints at full A4, CM5).
- **Download PDF (CM2):** made on the device with jsPDF: one A4 page (portrait or landscape) holding the 250 dpi sheet as a JPEG. File `calendar-YYYY.pdf`.
- **Background (CM2):** None, Soft colour (6 pale colours) or Picture (your image, downscaled to 1600 px and kept in localStorage `calendar-maker-bg`; Faintness slider 5-60 %). With a picture the months sit on white cards so dates stay readable. Applies to preview, print and PDF.
- **Holiday list (CM2):** optional strip at the bottom with date + name in 3 columns (same date names joined with " / ").
- **Holidays page (CM3):** Every year (fixed date; starts from the Calendar list; add, change date, rename, delete, Restore defaults) and This year only (dated holidays for the Design page's year; add, change date, rename, delete). Saved in `calendar-maker-holidays` right away on every add / rename / date change / delete / restore, loaded before the first draw; built-ins are copied only the first time you edit, so deleted ones stay deleted. A damaged key falls back to the built-in list; if the browser blocks saving, an in-app note says changes last this visit only. Custom holidays stay in Calendar Maker; the Calendar app is unchanged.
- **Dialogs:** UiDialog only (no browser alert / confirm / prompt).
- **Storage:** `calendar-maker-settings`, `calendar-maker-holidays`, `calendar-maker-bg`. Theme: own `theme` setting (CM15, About page); Auto follows the Calendar app (Dark default, System uses Hub pref `sites-hub.theme`, else the device).

## 4. Limits
- The PDF is one image (not selectable text); about 0.5-1.5 MB.
- Very long holiday names are cut with "…" in the strip; many holidays (40+) make the strip tall and the months smaller.
- A big picture may not fit in localStorage; it is then used for this visit only.
- **Fold 6th week (CM5):** default On. When a month needs 6 rows, its last dates (e.g. 30, 31) move into the empty leading cells of row 1 in the same weekday column, drawn smaller bottom-right under a thin diagonal; holiday/Sunday/Saturday tiles fill that lower-right half. Every month uses 5 rows. Saved as `fold` in `calendar-maker-settings` (missing = On). Off gives the plain 6-row grid.
- **Fill the sheet (CM5):** ~4 mm sheet margin, ~2.5 mm gaps between months, slimmer title band (120 px), months stretch to fill the rest in every layout, holiday strip only as tall as it needs, dates sized ~66% of cell height. Print image is full A4 (210x297 / 297x210 mm, `@page` margin 0); the PDF image is full A4.
- **Headers and colours (CM6):** title band fits the year tightly (110 px digits, ~1 mm gap below; was 130 px band). Each month's first grid row is the month name, merged and centred across all 7 columns, white with no fill, inside the border. Weekday row reads Sun Mon Tue Wed Thu Fri Sat (Mon first when the week starts Monday) on the holiday colour. Holiday colours are light print tints with black text: Green `#92d36e` (default), Red, Yellow, Blue, Orange, plus a Custom picker (`colour: 'custom'`, `custom: '#rrggbb'`). Font colour picker (`font`, default `#000000`) applies to title, month names, weekdays, dates, folded dates and the holiday strip. Both saved in `calendar-maker-settings`.
- **Design fixes (CM7):** folded 6th-week dates have no diagonal split or half tint; they are drawn at normal size and centred, and a holiday/Sunday/Saturday fills the whole cell. All grid lines in a month (outer border, under the month row, under the weekday row, between day cells) are `#333` 3 px, snapped to whole pixels (Excel 'All Borders').
- **Uniform grid (CM8):** the whole sheet is one spreadsheet-like grid. The month name row, weekday row, each date row and the gap between months all have the same row height; the 7 day columns and the gap between months all have the same column width (a month is 7 columns x 7 rows with the fold on, 8 rows with it off, gap = 1 cell). Cell size is the largest that fits inside the 4 mm margins, title band and holiday strip for the chosen layout. Month name, weekday labels and dates use one text size.
- **Restricted holidays (CM9):** every holiday (Every year and This year only) has a type, Gazetted (default) or Restricted, set with the type picker when adding and the chip on each row (tap to switch). Restricted rows are listed under a 'Restricted Holidays' heading below the main ones. Saved as `r: true` in `calendar-maker-holidays`; older saves and built-ins without it are Gazetted. On the sheet restricted dates get the Restricted colour (default light grey `#cfcfcf`, presets + custom, saved as `rcol` in `calendar-maker-settings`) with black text; if a date is both, Gazetted (holiday colour) wins; Sundays/Saturdays stay the holiday colour. The holiday list strip shows gazetted holidays first, then a 'Restricted Holidays' section, each in date order.
- **Holiday List page (CM10):** a third tab, Holiday List, shows a printable A4 portrait list for the chosen year: title 'Holidays YYYY', a Date | Weekday | Holiday table (Sun, Mon, ...), main holidays first in date order, then a 'Restricted Holidays' heading row (Restricted colour) and the restricted holidays in date order. Same holidays as the sheet (built-ins, Every year, This year only); Sundays/Saturdays are not listed. Header row on the holiday colour, all borders #333 same weight, white background, font colour from the Design page, 4 mm margins, row height and text size scale to fill the page (max 14 mm rows). An optional Header (e.g. organisation name, one line, max 80 characters, saved as `lhead` in `calendar-maker-settings`) is drawn above the title in the font colour; empty = not drawn, no space used. Print and Download PDF use the same 250 dpi canvas (render/cm_list*.js).
- **Multi-day holidays (CM11):** every holiday (Every year or This year only, Gazetted or Restricted) may have an optional To date. Every day from start to To gets the tile (Gazetted wins over Restricted on shared days). Ranges stay within one year and may cross a month end. In the sheet's holiday strip and on the Holiday List page a range is ONE row: '20–23 Oct' or '30 Sep–02 Oct', weekday 'Tue–Fri', name once, sorted by start date, restricted ranges in the Restricted section. A To date on or before the start is refused with an in-app note. Saved additively: every-year `em`/`ed` (end month 0-11 / day), this-year-only `end` ('YYYY-MM-DD'); old saves without them load as one-day holidays.
- **Holiday List layouts (CM12):** Layout select on the Holiday List page, saved as `llay` ('classic' default, 'simple' = CM10). Classic copies the hand-made Excel list: centred header block (organisation = Header, bold underlined; subtitle `lsub` default 'LIST OF HOLIDAYS', underlined; ':: ' marks toggle `ldeco`; the year in large spaced digits), columns Month | Date | Days | Holiday, header row colour `lhc` (default Excel blue #2e75b6, white text on dark colours, presets + custom), optional italic (a)-(d) row `labcd`, month merged down its rows `lmerge` (off = month on every row; restarts in the Restricted section), ordinal dates with superscript suffix ('14th & 15th', '17th, 18th & 19th', longer '20th – 28th', across months '30th Sep – 2nd Oct'), full weekday names, same-date names joined with ', ', long text wraps and the row grows. Font scales to fit one A4 portrait page. Print and PDF use the chosen layout.
- **Every-year input (CM11):** Day + Month selects (no year); the day list fits the month. 29 Feb can be chosen and applies only in leap years (skipped otherwise; a range ending 29 Feb ends 28 Feb in other years). This year only keeps the full date input.
- **Wide Holidays page (CM12-F1):** the Holidays page grows up to 1600 px; the two sections sit side by side on wide screens, the holiday name gets the spare room and each row's date, type chip and delete stay on one line; on phones rows wrap with the name on top.
- **Preview zoom (CM12-F2):** the Design sheet preview and the Holiday List preview each get a zoom bar: Fit (default) and a 25%-400% slider with % readout (100% = real A4 size). Ctrl + mouse wheel zooms around the cursor (plain wheel scrolls), drag pans when zoomed past fit, two-finger pinch zooms on touch. Display only (canvas CSS width): the 250 dpi render, Print and PDF are unchanged; re-rendering keeps the zoom (ui/cm_zoom.js).
- **Legend + month label fill (CM12-F3):** a small key band below the month grids (own band with ~2 mm gap, never touches a grid; text ~58% of the date font): swatch in holiday colour "*Holiday", plus "*Restricted holiday" only when the year has one. Toggle "Show legend" (`legend`, default on; off = no space). Month-name row fill `mfill` (default light grey #d9d9d9 like the Excel sheet; White = no fill; custom picker). All layouts, preview/Print/PDF.
- **Weekday row colour (CM16-F5):** the weekday label row of each month grid has its own fill `wfill` (default light grey #d9d9d9, same swatches as the month label fill, plus custom). "Match holiday colour" (`wmatch`, default off) restores the CM6 look where the row uses the holiday tile colour. Weekday text keeps the chosen font colour.
- **Original colours back (CM12-F4):** the holiday colour presets are again the original strong CM1-CM5 colours: Green `#15803d` (default), Red `#b91c1c`, Yellow `#facc15`, Blue `#1d4ed8`, Orange `#ea580c`; the CM6 light tints stay as extra presets Light green `#92d36e`, Light red (pink) `#f4a6a6`, Light yellow, Light blue, Light orange (`colour: 'lgreen'` etc.). Text stays black (font colour setting). The Custom picker's starting value is now `#15803d`; a saved custom colour or saved preset is kept. Weekday row, tiles, legend swatch and the Holiday List pages all follow the chosen colour.
- **Year Overview page (CM14):** a fourth tab, Year Overview: one A4 portrait 250 dpi page (zoomable preview, Print, Download PDF `overview-YYYY.pdf`) for the Design page's year, same holidays as the sheet (built-ins, Every year, This year only). Title band: optional Header (`lhead`), 'YEAR OVERVIEW', spaced year. Three all-borders #333 tables with header rows in the Holiday List header colour (`lhc`), font colour from the Design page, 4 mm margins; text shrinks (48 px down to 18 px) to fit one page; an empty table shows 'None'.
  - Day rules: off day = Sunday (always, whatever "Colour Sundays" says), Saturday holiday (Design page setting: None / 2nd & 4th / All) or any day of a Gazetted holiday. Multi-day holidays count every day. Restricted days are never off and never deducted; they are only counted and named.
  - Summary: Total days (365/366), Sundays, Saturday holidays (with the rule), Gazetted holidays (days), Gazetted on a Sunday / Saturday holiday, Total holidays (Sundays + Saturday holidays + Gazetted, overlaps counted twice), Actual holidays (each off day once), Working days (total − actual), Restricted holidays (days, not deducted).
  - Holiday streaks: every run of 3 or more off days in a row, longest first (ties by date), with From – To, days and the holidays in it ('Durga Puja + Sunday'; Sundays / Saturdays named only when they are not also Gazetted).
  - Holiday stretches (Jor's rule): a span that starts and ends on an off day, contains at least one working day, and has off days ≥ working days (restricted days count as working, named in brackets '(Restricted: …)'). The longest qualifying spans are picked first; any span overlapping an already picked one is dropped; all are listed longest first with Total / Off / Working.
- **Legend size (CM16-F1):** Design page number box next to Show legend, 0.5-2 em (step 0.05) of the date text size, default 0.58 (the CM12-F3 look). Saved as `lgsz` in `calendar-maker-settings`; clamped to 0.5-2, anything invalid -> 0.58. Swatches scale with the text; the legend band below the grids grows with it and the grids shrink to make room, so it never overlaps a month or leaves the page (all 4 layouts). Hidden while the legend is off; updates live as you type. Release label stays CM16.
- **Striped rows (CM16-F2):** Holiday List page "Striped rows" switch (default on) and "Stripe colour" presets light blue `#ddebf7` (default, Excel's light blue band), light grey `#ededed`, light green `#e2efda`, plus a custom picker. Saved as `lband` (bool) and `lbandc` (hex, invalid -> `#ddebf7`) in `calendar-maker-settings`. Classic and Simple layouts: 1st holiday row white, 2nd shaded, and so on; the count restarts after the Restricted Holidays heading (which keeps the Restricted colour). Classic with merged months: the merged Month cell stays white; with month on every row the Month cell follows its row. Grid lines (#333) and text colour unchanged; Year Overview tables unchanged. Legacy: before CM16-F2 lists had no stripes (= switch off, renders identical).
- **Show restricted holidays (CM16-F3):** Holiday List page switch (default on), saved as `lshowr`. Off: the Restricted Holidays heading and rows are left out of the list preview, Print and PDF (Classic and Simple), and the main holidays get the freed space. The calendar sheet tiles, its holiday strip and the Year Overview are not affected. Legacy: before CM16-F3 the section was always shown.
- **Year Overview title and sections (CM16-F4):** the overview title is just 'YEAR OVERVIEW' and the spaced year; the Header text is no longer drawn there even when set. Three sections titled Summary, Holiday Streaks and Holiday Stretches, with one blank table row between sections, counted in the one-page fit. PDF file names now start with the year: `YYYY-calendar.pdf`, `YYYY-holiday-list.pdf`, `YYYY-year-overview.pdf` (legacy: `calendar-YYYY.pdf`, `holidays-YYYY.pdf`, `overview-YYYY.pdf`). Legacy: CM14 to CM16-F3 drew the Header line above 'YEAR OVERVIEW', had longer section titles ('Holiday streaks (3 or more days off in a row)', 'Holiday stretches (days off ≥ working days)') and no blank row between sections.
- **Hub title bar (CM16):** tab order Design, Holiday List, Year Overview, Holidays (in-app row too). In a Hub Desktop window, after the Hub's `hubTitleBarHello`, the app sends `hubTitleBar` `set` (4 tabs, Print and PDF buttons, activeTab) and adds `body.hub-titlebar`, which hides the in-app top row. Page switches send `update` (activeTab, buttons; Print / PDF are greyed out on Holidays). Hub tab clicks call `CM.showPage`; button clicks run the active page's own Print / Download PDF. Messages are accepted only from `window.parent` with the right origin and shape. Standalone, file:// without Hub and Phone mode keep the in-app row. CM15 added About as the last tab (5 tabs).
- **About page (CM15):** fifth and last tab (in-app row and Hub title bar; Print / PDF greyed out there, like Holidays). One centred column (max 640 px) of three cards. Settings: Theme Auto / Light / Dark, saved as `theme` in `calendar-maker-settings` (invalid -> 'auto'). Auto = the CM1-CM16-F5 behaviour (follow the Calendar app's theme: its Dark default, or System = Hub pref `sites-hub.theme`, else prefers-color-scheme; live on storage / device changes). Applied as `html.dark` (+ `data-cm-theme`) by the head script and `CM.applyTheme`; only the app screens change, never the sheet, list, overview, Print or PDF (golden check identical). 'Reset to defaults' (UiDialog confirm) sets every design / Holiday List setting back to default, keeping year and theme; holidays and the saved picture are never touched; the page reloads. How to: short steps for Holidays, Design, Holiday List, Year Overview, Print / PDF file names. About: name, release label, one-line description, works offline, saved in this browser's storage.

- Hub title bar (CM16): untested in a real Hub browser window; the app name in the in-app row is hidden too (the Hub shows it). No keyboard page shortcuts exist, so only clicks switch pages.
- Year Overview (CM14): a stretch can be as short as 3 days (off, working, off); with very many holidays the text can reach 18 px and very long lists could still overflow the page.
- **Holiday CSV export / import (CM17):** About > Settings, buttons 'Export holidays (CSV)' and 'Import holidays (CSV)'. Header `Name,Start,End,Type,Repeat`; Type Gazetted / Restricted; Repeat Every year (Start/End `DD-MM`, 29-02 allowed) or This year (`YYYY-MM-DD`); End blank = one day. Export writes every holiday (every-year list, or the built-ins when never edited, plus all this-year-only entries) as UTF-8 with BOM, CRLF, quoted names, file `YYYY-holidays.csv` (selected year; Blob + a[download], works from file://). Import: BOM optional, CRLF or LF, Type/Repeat any case, columns by header name (End column optional). Rows skipped with line number and reason: missing name, unknown type / repeat, bad start / end date, end before start, range crosses into another year. Preview dialog 'N holidays found, M rows skipped' then Add to existing (duplicates = same name + dates + repeat skipped and counted) or Replace all (second confirm; duplicates inside the file dropped). Nothing is saved before that choice; Cancel saves nothing. Then the Holidays page, sheet, list and overview refresh.
- **Remember the year (CM17-F1):** the page opens on the last year you picked (saved `year`, 1900-2200); a missing or broken value falls back to the current year, and `?year=YYYY` from the Calendar app still wins. Legacy: CM1-CM17 always opened on the current year.
- **Year Overview dates and names (CM17-F2):** in Holiday Streaks and Holiday Stretches the From – To cell shows ordinal dates with a superscript suffix, like the Classic list ('23rd Jan – 27th Jan'), with a smaller second line '(Friday to Tuesday)'. Holidays in it lists every off day in date order joined with ' + ': holiday names (a multi-day holiday once, at its first day in the run), 'Saturday' / 'Sunday' for weekend days with no Gazetted holiday, Restricted holidays as '(R) Name'. Example 2026, all Saturdays off: 'Netaji Jayanti + Saturday + Sunday + Republic Day + Busu Dima'. Cells wrap; the page still shrinks to fit. Totals and working-day columns unchanged.

- **Holiday types (CM18):** four types, Gazetted, Restricted, Public, School (no 'General'). Saved as r:true (Restricted, unchanged) or t:'p' / t:'s'; old saves load unchanged. Holidays tab: a type select on each row and on both Add rows; blocks Gazetted, Restricted, Public, School. Calendar tile priority on a shared day: Sunday > Saturday holiday > Gazetted > Restricted > Public > School. Design: Public colour (default purple #d9d2e9; blue, pink) and School colour (default yellow #fff2cc; orange, teal) plus Custom; legend shows a type only if the year has one. Lists: Public Holidays and School Holidays sections after Restricted, headings in the type colour, with Show public / Show school switches (on by default). Overview: Public and School counted (not deducted) and named '(P) Name' / '(S) Name'; their summary lines appear only when the count is above 0. A day counts once, as its highest type. CSV: header name,start,end,type,repeat; type gazetted|restricted|public|school; repeat yes|no; import still reads the CM17 format and y/n/true/false, any case.
