Can't Open YouTube ?

Certain websites (including YouTube) are blocked on this network at the DNS level.

Switching to a different DNS server — such as Google (8.8.8.8) or Cloudflare (1.1.1.1) — can restore access to them.

Method 1 — Private DNS (recommended)

  1. Open Settings.
  2. Tap "Network & Internet"
  3. Tap "Private DNS"
    If not visible, check under "Advanced" first
  4. Select "Private DNS provider hostname"
  5. Enter one hostname from the table below
  6. Tap "Save"
Provider Hostname to enter
Google (8.8.8.8) dns.google
Cloudflare (1.1.1.1) 1dot1dot1dot1.cloudflare-dns.com
Private DNS only accepts a domain name, not a numeric address — the hostnames above correspond to the IPs shown in brackets.

Method 2 — Per-network DNS (alternative)

Some devices allow setting DNS per WiFi network instead, using numeric addresses directly.

  1. Open Settings → Network & Internet → Wi-Fi
  2. Long-press the connected network, tap "Modify network"
  3. Expand "Advanced options"
  4. Set IP settings to "Static"
  5. Fill in the following fields:
    IP address: any unused address between 10.10.10.101 to 10.10.10.150
    Gateway: 10.10.10.1
    IP mask: 255.255.255.0
  6. Fill in the DNS fields:
    Cloudflare — Primary DNS: 1.1.1.1, Secondary DNS: 1.0.0.1
    Google — Primary DNS: 8.8.8.8, Secondary DNS: 8.8.4.4
  7. Save and reconnect
Two devices cannot use the same IP address at the same time — if the connection fails, try a different number within the range.
That's it. ✅

Quick Troubleshooting

  • Don't see "Private DNS"? Search "Private DNS" in the Settings search bar.
  • Still not working? Try switching between Cloudflare and Google.
