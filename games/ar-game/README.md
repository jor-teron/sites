# AR Theme Game

Phone camera AR-style game.
Default theme: Pet (chase and tap to catch).
DLC stubs: Zombie, Ghost.

## Run
Open ar-game.html (or the folder index.html) over HTTPS or localhost (camera requires a secure context).
On phone: same Wi‑Fi, serve the folder, open in Chrome.

## Notes
Three.js r160 is vendored locally at vendor/three.min.js (no CDN needed).
Placeholder shapes only. Swap GLB models later in assets/models/<theme>/.
